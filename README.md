# Generated Test Cases

AI-powered test case generation from User Stories.

## Workflow

1. **Requirements Analysis** - Extract User Story from Google Doc
2. **Test Case Generation** - Generate CSV with DeepSeek AI
3. **GitHub Import** - Commit to repository

## Usage

```bash
python scripts/generate_tests.py --story US-001
```
